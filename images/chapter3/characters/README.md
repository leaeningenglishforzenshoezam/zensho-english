# 第3章・バドの立ち絵（5枚）

このフォルダは GOIMON QUEST 第3章のキャラクター素材置き場です。

## 準備済みの5つの画像ファイル名

| ファイル名 | ゲーム内の役割 | 元の画像 |
|---|---|---|
| `ch3_bado_normal.png` | 初登場・山小屋での日常・模擬戦前・別れ | シャトルコックゴリラの怒れるポーズ.png |
| `ch3_bado_alert.png` | バドとの模擬戦・脱出した二人を追う場面 | 激昂シャトルコックゴリラ.png |
| `ch3_bado_conflicted.png` | 負傷ゴイモンを見て戸惑う・ヒロトシの命令をためらう | 葛藤するバドの四つ這い姿.png |
| `ch3_bado_defensive.png` | バド対決ルート・進路をふさぐ | 守護するバドの咆哮ポーズ.png |
| `ch3_bado_ally.png` | バド共闘ルート・ヒロトシの斧に立ちはだかる | 守る決意のバド.png |

**素材本体はまだこのフォルダにアップロードされていません。** 今回のチャットで整理・透過処理したPNGを、上記の名前でこのフォルダに配置してください。実装済み `battle-prototype/chapter3_assets.js` がこのパスを参照しているため、配置されると各場面で自動的に表示されます。

- 5枚とも背景透過PNGに統一して使います（元画像のうち「激昂」「守護する咆哮」は黒背景だったため処理済み版を使用）。
- 別チャットで制作する画像は、基準となるこのバドの姿を参照してください。
- 第3章は開発ブランチ `feature/chapter3-story-choices` で検証します。**mainには直接追加しない**でください。

画像制作全体の仕様は `docs/chapter3_asset_plan.md` を参照してください。
