# 2級大問11 Mac 実機チェック（テストアカウント専用）

## 前提
- `feature/grade-2` ブランチをローカルに取得する。`main` にはマージしない。
- 既存の個人・生徒用Googleアカウントでテストしない。テスト専用プロファイルを使う。
- Mac のターミナルでリポジトリのフォルダ内から `python3 -m http.server 8765`、その後 `http://localhost:8765/g2q11_diagnostics.html` にアクセスする。
- この診断は読み取り専用。クラウドWorker側の受け入れ可否は検証しない。

## 順番
1. 診断ページ：200問・ID・選択肢・2級カテゴリー・保存キーの全項目を確認
2. ホームで2級を選択→大問11→`g2q11.html` に移動することを確認
3. 問題一覧・文法一覧：一覧数、タグ別全問演習、単問演習を確認
4. 正解：学習ログに1件加算、ことば＋0.5・ぶんみゃく＋0.5を確認
5. 誤答：自動苦手登録と誤答回数＋1を確認
6. 手動苦手：登録・解除後に再読み込みして保存状態を確認
7. 苦手優先：苦手登録問題が先に出て、誤答の多い順になることを確認
8. 1級を選択してから新2級ページへ直接アクセスし、演習開始が阻止されることを確認
9. 別タブで学習操作した際の競合警告と復旧データを確認（可能であれば）
10. Workersを更新していない現状では、クラウド同期の成功判定を行わない

## リリース不可の条件
- 学習ログ保存後に育成加点が失敗した場合の復旧方法が確定していない
- Worker本番の `cloud_schema.js` が更新されていないため、苦手データの別端末同期は保証できない
- 端末で上記操作テストが完了していない
- `feature/daily-missions` と将来マージ時の競合確認ができていない

## 安全
- テストのためにmain、Workers本番、D1本番を変更しない
- 診断ページを開くだけで既存データの変更はしない
