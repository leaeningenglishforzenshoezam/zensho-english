# GOIMON QUEST 第3章「山道の罠」画像制作仕様書
版: 2026-11-17 / 対象: 開発ブランチ `feature/chapter3-story-choices`

## 必須方針
- 2026-11-17: **バドの5ポーズはユーザーが制作済み**。本チャットで正しいファイル名への整理と黒背景2点の透過処理を行い、ゲームでの場面ごとの使い分けを実装済み。ただし **PNG本体のGitHubへの登録はまだ**で、別途 `images/chapter3/characters/` にアップロードが必要。
- 以下の一覧は画像制作・配置に使う **実装済み参照パス** と **必要素材** の一覧。
- 画風は第1・2章と整合する2Dフラットイラスト。輪郭と色面が明快、単純な線、色の数は控えめ。グラデーション、3D、過剰な装飾、AI特有の細線や不自然な部品を避ける。
- 背景・イベント絵は横長16:9、制作・納品目安1920×1080 px、PNG。**文字、字幕、UI、ロゴを入れない。**
- キャラクターは背景透過PNG。人間の立ち絵は縦長約1024×1536 px、バド・ほかのゴイモンは全身が収まる約1536×1024 px。ギリギリに切らず余白を確保する。
- 同じ建物・家具・庭・山道は、角度を変えても同じ場所に見えるよう「家と庭の位置関係」を統一する。背景に固定の人物やゴイモンを描き込まない（イベント絵は例外）。
- デザイン基準にするため、最初に `ch3_hirotoshi_normal.png` と `ch3_bado_normal.png` を作り、以後の全イラストはその2枚を参照する。
- **ヒロトシはバドの言葉を理解できない**。表情としぐさで関係を見せる。人間とゴイモンの共鳴演出を勝手に追加しない。
- 傷ついたゴイモンや肉料理は不気味さを表すが、流血・切断・人体の直接描写は不要。シナリオの意味を損なわない範囲で非グロテスクに描く。

## 地理の統一設定（背景の重要な基準）
トシャカへ向かう山道の中腹にヒロトシの山小屋がある。山小屋の裏側に**囲いと作業用の庭**、庭の端に**木箱・薪・丸太**が積まれた薪小屋がある。庭の外へ下る山道は曲がっており、**山小屋の裏手へ近道で先回りできる分岐道**がある。決戦はその分岐道の**薪・丸太・木箱の近く**（遠くの別の場所ではない）。監禁部屋は石壁と厚い木扉、高い小窓がある同じ部屋。窓からは裏庭の囲いが見える。

## F. 制作順序と参照の引き継ぎ
1. **バド基準絵（C05）**と**ヒロトシ基準絵（C01）**を確定。表情・装飾・色を勝手に変えず、後続制作時にその画像を毎回添付する。
2. **地理の基準背景B02（外観）とB07（庭）とB08（薪小屋沿いの小道）**を制作。家、囲い、薪、小道の相対位置を固定する。
3. B01/B03/B04/B05/B06/B09/B10/B11を制作し、部屋の窓の高さ・庭を見下ろす角度・トシャカ側の世界観を連動させる。
4. C10・C11・E01、ヒロトシ・バドの表情/戦闘差分C02〜C04/C06〜C09を制作。
5. 最後にV01〜V04を、完成した背景とキャラクター基準絵を参照して制作。イベントCGで外見が変化しないようにする。

## H. 実装との連携・ファイルの置き方
- 上記ファイルは `battle-prototype/chapter3_assets.js` へ登録済み。

- 第3章の画像のうち **バド5枚は制作・透過処理・ZIP化済み**。GitHubリポジトリへのPNG本体のアップロードは未完了。アップロード後は19シーンの指定場所で自動表示される。
