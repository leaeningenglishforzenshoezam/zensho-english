# 2級 大問11：既存GOIMONへのシンプル統合

## 方針
既存の学習カテゴリ・学習ログ・GOIMON育成・クラウド保存を使う。大問11専用Cloudflare Worker/D1を作らない。mainや本番データは事前承認なしに変更しない。

## 既に開発ブランチで接続した箇所
- `index.html`：2級→`g2q11.html`、1級→従来の`paraphrase_quiz.html`。
- `learning_categories.js`：2級のみ`q11_grammar`を登録。
- `learning_log.js`：既存の2級ログへ正誤記録。
- `goimon.js`：既存GOIMONへ正答1問につきことば0.5・ぶんみゃく0.5。
- `cloud_schema.js`：既存クラウド保存で2級大問11の苦手記録キーを許可。
- `g2q11*.js/html/css`：問題200問、3択、解説、文法一覧、苦手登録。

## 今回の整理
使用していなかった報酬台帳の別準備APIを削除。正解を記録する既存学習ログに未付与IDを含める方式は維持し、重複加点と保存失敗からの復旧を保つ。

## 統合前の残作業（必要最小限）
1. 開発ブランチの自動テストに合格すること。
2. Macブラウザで設定→回答→苦手登録→再読み込みの操作を確認。
3. 本番Worker側の`cloud_schema.js`が新しい苦手キーを受け入れるか確認。未対応なら既存Workerの共有スキーマだけを本番反映時に合わせる（独立環境は不要）。
4. `main`へ統合するのは明示的な承認後。生徒の既存記録を上書き・初期化しない。

ステージング検証資料は開発ブランチに残すが、新しいCloudflare環境の構築は行わない。
