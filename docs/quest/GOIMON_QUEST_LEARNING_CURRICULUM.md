## 1. 最終目標
- 最終的な「全クリ」は**全商英語検定1級に余裕をもって合格できる実力**を養い、複数技能の初見問題・期間を置いた復習・総合試練によって実証することを目指す（合格保証ではない）。
- 物語完走と学力習得は異なる。通常クリア（ストーリー進行）／マスター（技能定着）／完全制覇（総合習得）の3層を**提案**。勝利だけで単語・読解・聞き取りの習得済みとしない。
- 1級対策を主軸にするが、2級や公開中の既存機能は維持。学習範囲と出題形式は正式な検定資料を別途照合。

## 3. クエスト領域と学習の対応（地名も章数も仮）
- ことばの森：語彙の基礎、英→日／日→英、復習。現行第1エリアのSTAGE1〜5の単語範囲案を維持しつつ精査。
- 響きの谷：アクセント・音と意味、聴解の短問。
- 会話の街：リスニング大問2・3、会話のやり取りと状況判断。
- 熟語の洞窟：熟語、同義表現、大問11。
- 文脈の高原：大問9 A/B、語法・文脈判断。
- 読解の遺跡：大問7/8/10の読解・会話・文章理解。
- 構文の塔：整序・文法・英文構造、大問12。
- 聴解の海：長めのリスニング、大問5、将来の大問4/6。
- 総合試練：技能横断・初見模擬・弱点補強。
以上は**学習エリアのサンプル**。複数章で技能を繰り返し登場させ、語彙だけを終えて二度と出ない構造にはしない。冒険ストーリーはこの地名に縛られず組み直す。

## 4. 習得判定の原則（数値は後決め）
- 解答イベントは問題ID・技能・出題形式・初見/既習・回答正誤・日時・復習の結果と安全に関連付ける。
- 戦闘勝利と習得は独立評価。高火力技の利用は楽しい戦術だが、未学習範囲を『習得済み』にはしない。
- 既習問題を繰り返すだけで完全制覇を認めず、初見または等価な新問題で移転可能な理解を確認する。
- 一定期間経過後の再確認（定着）を含める。誤答時は既存学習画面への導線を設ける。
- 聴解・長文・整序は単語4択では代理しない。実際の素材や形式で評価する。
- 強い呪い/ボス戦は異なる技能の混成によって緊張感を出すが、学習の失敗へのペナルティを過剰にしない。
- 検定の年度ごとの出題形式、合格基準は正式資料で確認する。

## 5. ゲーム進行とのリンク
物語イベント → ステージ（新しい技能を使用）→ 通常戦 → 特殊戦・黒い霧（復習や複数技能）→ 番人/ボス（定着確認）→ 次の章、という基本サイクルを検討。
- 章数を6に固定せず、ボリュームは技能の習得に必要な演習量から逆算。
- 物語イベントは短く、見返し可能・スキップ可能にする。
- 既存の『ステージ0と5戦』試作は長編序章の基礎とし、全ゲームの長さとはみなさない。
- 以前の戦闘仕様（敵HP、時間制限、技使用回数、エリア内残HP等）は作業中に変更があるため、学習カリキュラムの確定値として固定しない。
