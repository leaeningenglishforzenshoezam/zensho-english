# 第1章ノベル脚本 改訂指針・導入〜モリィ Ver.3
2026-10-17／本稿はゲーム表示用脚本の改稿案。既存クエストコード・プロフィール保存形式は未変更。

## 人名差し込み
- 物語中の「主人公」発話ラベルおよび呼びかけは `{{playerName}}` を使う。表示時にプロフィールに登録された**プレイヤーの名前**を取り出し、テキストとして代入する。
- ゴイモン固有の「ニックネーム」は主人公名ではない。プロフィールのプレイヤー名を誤ってゴイモン名から取得しない。
- 名前未設定時は「あなた」または発話ラベル「主人公」を使用。未設定を勝手にプロフィールへ保存しない。
- 既存のログイン・保存情報には触れない。プロフィール名の実データ参照キーは未特定のため、既存プロフィール画面の実装確認後に確定する。
- XSSを防ぐためHTML文字列連結で代入せず、DOMのtextContent等で表示する。

## ゲーム内の世界・人物の前提
- 人間とゴイモンが共存しているが、現在は両者の言葉が通じない。人間同士とゴイモン同士の言葉は通じる。
- `{{playerName}}` と相棒ゴイモンは、以前から一緒に暮らす身近なパートナー。まだ言葉で会話したことはないが、仕草や日々の経験で気持ちを伝え合ってきた。
- 森の入口から古い道を散歩しているのは、相棒が見つけた見慣れない光る印が気になり、主人公が一緒に確かめに来たため。冒険を予言する人物に命じられたわけではない。危険だとは思っておらず、日が高いうちに引き返す予定だった。
- この森の特別な石碑は一基だけ。導入では石碑が共鳴を引き起こすような説明をしない。

## モリィの脚本ルール
- 普段は親しみやすい案内役。道案内、軽口、主人公たちへの気遣いが会話の大半を占める。
- 「……」「知らない」「そのうち」「昔は」「まさか」などで意味深に止める会話を連発しない。
- 伏線として意図的な言いよどみを置くのは第1章全体で少数に絞る。重要な例は第1章終盤の「また、見つかったのか」。
- モリィが落石を仕組んだ事実は中盤以降の開示。今回の導入では偶然出会ったように見せる。
- 相棒の台詞は声が届くようになった後から通常の会話として表示。それ以前は身振りや鳴き声として書く。
- **表示仕様**：モリィや番人の言葉は、相棒が介在する世界設定を維持しながらプレイヤーには直接字幕で表示。通訳を説明する地の文も、逐語的な通訳セリフも挿入しない。
