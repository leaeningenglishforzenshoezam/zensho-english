# 公開前チェックポイント（2026-10-29）

作業ブランチ: integration/release-safety-20261027。main・本番 Cloudflare は未変更。

## 今回の仕様

- クエストは egg / child / growth のみ参加可能。mid / final と不明な段階は不可。
- 育成・保存箱・図鑑の中級体・上級体は削除しない。
- 出発時だけでなく、以前のセーブ再開・戦闘開始時にも参加条件を確認する。
- 参加不可になった旧編成は保存を消さず、使用できる相棒で章の冒頭から再挑戦する案内へ。
- 第1章・第2章とも途中、ゲームオーバー、クリア後から再挑戦可能。
- 編成画面を開いただけでは保存を変更しない。最終確認に同意してから保存する。
- 第1章も scene 0 / line 0 に戻す。途中の scene 6 からは開始しない。
- 今回の戦闘・HP・技回数は初期化。既読・クリア履歴・章解放・育成・学習・所持品は保持。
- 第1章の練習は再実施できるが、一度受け取った練習プレゼントの受領状態・抽選済み装備は保持。
- 同時更新を検出した場合は上書きしない。

## 残る公開条件

1. ユーザーのPCから本番 Cloudflare に接続し、必要なマイグレーション・設定を確認する。
2. 本番 Google ログインで既存データをバックアップし、ログイン・保存・別端末再開を検証する。
3. ほしのかけら・ガチャ所持品の正式クラウド保存／重複付与防止は未接続部分が残る。単純な同期対象追加で済ませない。
4. 教師向けクラス・課題 API は承認教員と機能フラグの設定、実接続テストが必要。
5. スマートフォン実機で編成不可案内、再挑戦のキャンセル／確定、物語・戦闘画面を確認する。

自動テストは本番ログイン・実データの安全性を完全に保証するものではない。上記を完了する前に main へ公開しない。
