# GOIMON QUEST｜500語×3形式 完全網羅プラン Ver.1
2026-10-17／設計決定。クエスト画面への接続・セーブ実装は別工程。

## 設計原則
1級単語データ `words_1kyu.js` の**実データ500語（1〜500）**を母集団にする。既存ブロックは1〜50, 51〜100, …, 451〜500の50語×10区間とする。ソースコメントの「499語」は実数と不一致だが、既存番号を変えない。

**すべての単語について次の3形式を1回以上出題する**：
- `en_to_ja` 英語→日本語（読んで意味を取る）
- `ja_to_en` 日本語→英語（意味から語を選ぶ）
- `audio_to_ja` 英語音声→日本語（音から意味を取る）

必須学習出題数＝500×3＝**1500問（初回網羅分）**。復習・ボス・定着判定は**1500問に追加**する。各ステージ10問の例なら150ステージ分、5問なら300ステージ分に相当するが、ステージの構成と戦闘1回の出題数は別設計で決める。無理に150ステージを1エリアに押し込めず、章間で3形式を交互に繰り返す。

## クエスト進行（案）
1. 新エリアでは「英→日」で語義に出会う（序盤の戦闘）。
2. 同じ50語の「日→英」を別の戦闘で使い、逆方向の検索を練習。
3. 同じ50語の「音→意味」をリスニング系ステージで解く。**音だけで識別すること**が必要なので、設問の英字表示や他の視覚ヒントに注意。
4. 各50語区間の番人は3形式混合で復習。ボスは以前の50語区間も出す。
5. 500語すべてについて3形式の初回出題を終えたら、弱点再挑戦・期間を置いた定着テスト・混合総合試練へ。
6. 大問9 A/B・アクセント・長文などへ橋渡しし、単語を選択肢だけでなく文中で再認識する。
7. ストーリーと技能育成は並走。単語エリアだけで長編を使い切らず、全大問で横断的に復習する。

## 進捗キー・採点の仕様（提案）
- 進捗の基本単位は**[級, 単語の恒久識別子, 出題形式]**の3要素。現在の配列indexだけに依存せず、初回導入時はindex 1〜500を保ちながら語句の変更にも耐えるIDを決める。
- 各単語×形式で `presented`, `attempts`, `correct`, `lastAnsweredAt`, `mastered` 等を区別。**「提示された」だけで習得済みにはしない**。
- 最小網羅率＝全1500セルに対する「出題経験あり」の比率。正解網羅率と定着率は別表示。
- 誤答は取りこぼしキューへ送り、再挑戦可能にする。正解しても後日再確認しなければ完全マスターにはしない。
- ボス・技・装備の火力によって戦闘が短縮されても、未出題のセルはスキップしたままにならない。後続ステージまたは補充戦闘で必ず回収する。
- 途中離脱・再開、Google同期、ゲストデータ移行を考慮し、既存記録を無断リセットしない。複数端末の競合時は解答履歴を単純上書きして喪失しない設計が必要。

## 選択肢と音声の品質
- 英→日は同品詞・意味の近い選択肢を中心にしつつ、正解が2つになる選択肢を避ける。
- 日→英では多義語・類義語で同時に複数正解にならないようにする（特に同じ日本語訳を持つ語）。
- 音→意味は既存 `audio_quiz.js` の音声再生/解答UIを再利用できるか優先検証。ブラウザTTS利用なら音声品質・アクセント・端末間差の点検が必要。
- 常に初見ランダムにせず、新規範囲の未出題セルから優先して取り出す。周回では弱点・復習期限・難易度を優先。
- 既存の学習報酬・成長ポイントとの二重付与を防ぐ。戦闘イベントで採点・報酬が二重に計上されないよう連携。

## 品質ゲート
- 500単語の3形式で重複・欠番なし（計1500セル）。
- 範囲1〜500の端点、各50語の区切り、出題シャッフル、再開位置のテスト。
- 誤答→弱点登録→再挑戦→正答→復習対象維持のテスト。
- 音声再生失敗/非対応端末時に音声問題を正答扱いして進めない。
- 既存の「英→日」「日→英」「音→意味」の3教材が正しい単語リストを使い、画面遷移しても学習履歴が失われないことを確認。
