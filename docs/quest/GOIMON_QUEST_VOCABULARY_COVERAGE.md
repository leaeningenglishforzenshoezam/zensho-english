# GOIMON QUEST｜単語学習とクエストの役割分担 Ver.2
2026-10-17／従来の「クエストで500語×3形式を全出題」案を撤回して更新。

## 正式方針
**網羅的な演習は既存の学習画面で行う。クエストは学習の成果を試す場所とする。**
- 1級単語1〜500の英→日、日→英、音声→意味の3形式は、学習画面で学べるように維持する。
- クエストの戦闘で500語×3形式=1500セルを必ず出題する必要はない。クエストは対象範囲から適切に抽出した問題を解いて進む。
- クエストに勝てない／同じ範囲で誤答が続く＝その領域の演習が不足している可能性。戦闘後に**該当する学習画面の範囲・形式へ直接戻れる導線**を用意する。
- クリア後には次のエリアへ。負けた場合は学習して再挑戦する「演習→挑戦→苦戦→追加演習→再挑戦」のループを中心にする。
- 技・装備の強さだけで学習不足をすべて覆せないよう調整する一方、得意な問題に自信を得る体験を保つ。
- クエスト未出題の単語があっても正常。未出題数をクエスト制覇の直接条件にはしない。学習画面の網羅進捗と、クエスト突破を**別指標**にする。

## 500語の扱い
- `words_1kyu.js` 実データは500レコード。既存の順序・ID対応は維持。
- 50語×10ブロック（1〜50、51〜100、…、451〜500）を、学習画面の範囲指定とクエストの出題プールで共通利用する。
- クエストではブロックから偏りの少ない抽出を行い、毎戦全件は出さない。特定の問題ばかり出る/同じ問題が連発する偏りを制御する。
- 3形式はすべて学習画面で利用できるが、クエスト内の登場頻度・設問形式はステージに応じて設計する。音声→意味に失敗した場合は音声クイズへ、日→英なら日→英クイズへ遷移する。

## 学習への帰還UIの具体案
戦闘敗北または途中撤退時：
- 「あと一歩！ 51〜100の日本語→英語を練習すると勝ちやすくなるよ」のように、**実際に誤答した問題形式と範囲をもとにした**提案を表示する。
- 「この範囲を学習する」→対応する既存演習画面に範囲・形式を渡す。
- 「もう一度挑戦」→同ステージへ戻る。
- 学習からクエストへの戻り先も保持。現在の進捗・セーブ形式を破壊しない。

## 制覇/成長の表示
- 「学習画面の範囲別習熟（英→日、日→英、音声→意味）」と「クエストのステージ達成」は独立して表示。
- 学習画面の演習履歴が不十分でも、クエスト自体への挑戦を一律禁止しない。実力があれば勝てる。
- 学習が不十分だからという理由で敗北を確定させるのではなく、実際の解答を評価する。
- 「全商英検1級の力がついた」という評価は、単純なボス撃破だけで断定しない。総合演習や実戦形式の学習履歴も参照する。
- 大問4・6の音声実装は後期工程。現段階のクエスト開発を妨げない。

## 品質チェック
1. 範囲1〜500を正しく指定できる（50語ブロック境界・最終500）。
2. 敗北時に該当する技能・ブロックの学習画面へ遷移できる。
3. 該当形式の学習を終えたら元のクエストに戻れる。
4. 無根拠に「演習不足」と断定せず、苦手の具体情報から学習を提案する。
5. 学習履歴とクエスト進捗の同期・保存を混同せず、既存データを維持する。
