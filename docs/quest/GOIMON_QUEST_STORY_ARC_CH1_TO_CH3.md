## 不変の世界設定
昔、人間とゴイモンは対等に言葉を交わせた。古代には一部の人間による強制支配術が生まれ、それを止めるため？？？が生命を封印の核にした。特定の人間とゴイモンの相互理解「共鳴」は世界封印を解除しない。森の丸い石碑（右上欠け、斜め傷、五本指手形と丸い三本指足跡）は一基だけ。黒い霧は封印の自動修復。モリィは？？？の古代の相棒で落石を意図的に起こしたが、読者に早期開示しない。

## 第1章｜聞こえた言葉（章題仮）
**問い：なぜ自分たちだけ言葉が通じるのか？**
1. 落石事故。主人公と相棒が互いを守り、共鳴が起きる。驚きとユーモアある初会話。モリィが現れ、森の異変と石碑へ誘う。
2. 石碑が共鳴に反応。古い手形と足跡、傷が示される。石碑は共鳴を生む装置ではない。
3. 封印の番人たちが侵入を拒む。彼らは悪者ではなく、命令と自我の間で揺れ始める。既存のチュートリアル＋5戦を基礎として配置。
4. 黒い霧が独自に作動し、番人の意思まで飲み込もうとする。主人公と相棒が共鳴を保って突破する。
5. 石碑から断片的な古い「人とゴイモンが笑い合う記憶」を垣間見る。全文・封印理由・落石の真相はまだ見せない。
**章末フック（採用）:** 守護者の迷いを見た主人公たちが、黒い霧に襲われる番人を助ける。石碑には人間とゴイモンが笑い合う古い記憶だけが映る。霧は森の外へ流れ、別の共鳴者の危機を示唆する。モリィは「また、見つかったのか」と口を滑らせる。主人公は同じ危機にいるかもしれないペアを助けるため旅立つ。**「ほかに共鳴者がいるらしい」だけを旅立ちの動機としない。**
**教材の方向：**単語・熟語・アクセント（学習画面で練習／クエストは一部を抽出）。数・場所名はシナリオ完成後に決める。

## 第2章｜もう一つの声（章題・場所仮）
**問い：言葉が通じれば、必ず信頼できるのか？**
1. 主人公たちは森の外へ流れた黒い霧を追い、危機にある別の共鳴ペアに遭遇する。その道中で、他の人間とゴイモンが意思疎通できない現実を目撃する。共鳴を「奇跡」と受け取る人と「危険な力」と恐れる人がいる。
2. 別の共鳴ペアと出会う。片方は主人公たちを助けるが、もう一方はゴイモンの安全のため、共鳴者を公にするべきでないと主張する。
3. 小さな事件：善意で通訳した内容が、当事者の意図とずれて誤解を生み、ゴイモンが危険にさらされる。「理解できる」と「正しく伝えられる」の差が表面化。
4. 対立相手は実際にゴイモンを守ろうとしていると判明。共通の敵となる黒い霧の干渉に際し、利害の異なる二つのペアが共闘する。
5. 完全和解はしない。主人公は「理解を広めたい」、相手は「二度と利用されたくない」という目的を抱え、道を分かつ。
**章末フック：**共鳴が危険だとする古い記録に、「言葉を通じさせる力はかつて命令に変わった」とある。
**教材の方向：**大問1・2・3／熟語・大問8。音の聞き取りと会話の流れをテーマに。大問4・6は使わない。

## 第3章｜命令された言葉（章題・場所仮）
**問い：誰が、何からゴイモンを守るために封印したのか？**
1. 主人公たちは第2章の記録の出所を探る。古い建物や文書に、人とゴイモンが協力していた日常の記録を見つける。
2. その裏に、言葉を一方的な命令として利用する支配術の痕跡がある。すべての人間が加害者だったわけではなく、抵抗した人々も描く。
3. 記録の解読をめぐって「封印は解くべきだ」「解けば再び支配が始まる」という見解が衝突する。第2章の共鳴者の警告が理解できてくる。
4. 文献にはモリィらしき姿や足跡が残る。しかし何百年前に生きていたはずのゴイモンが今そばにいる理由は説明しない。主人公に初めて疑念が生まれる。
5. 古代の抵抗者が、大きな犠牲と引き換えに人とゴイモンの通路を閉じたと示唆される。？？？の正体と現在の姿は伏せる。
**章末フック：**主人公たちが初めて出会った森の石碑と同じ傷の意匠が文書に描かれ、その傷が単なる事故ではない可能性が浮かぶ。二つ目の同じ石碑は登場させない。
**教材の方向：**熟語・大問9・11と大問7/8/10の長文・会話資料を組み合わせ、文脈に基づく判断を求める。

## 章とステージを増減させる基準
- **章：**主人公の目的・関係性・世界の理解が大きく変わる転換点で区切る。地名は脚本の内容から命名。
- **エリア：**物語上の移動・敵の事情・教材の主題に自然な区切りがあるときだけ作る。
- **ステージ：**意味ある戦闘、問題形式の変化、事件、ボス戦に合わせて増減。各エリア5ステージ固定を廃止。既存5戦は利用。
- **復習：**クリアのために500語全件をクエスト内で出さない。勝てなければ対応する学習画面へ。
- **伏線：**第1章の手形と足跡、第2章の危険性、第3章の古代史を積み重ね、中盤にモリィの工作、終盤に封印の核を明らかにする。
- **未確定：**第2章の共鳴ペアの名前、事件の正確な原因、各章の最終対決、終幕は今後具体化する。

## 第1章終盤の採用シーケンス（2026-10-17更新）
1. 最終守護者を退け、石碑の記憶を部分的に解放する。
2. 人間とゴイモンが昔、笑い合っていた光景が一瞬だけ見える。そこに人間らしい影と、封印の核「？？？」からの声が割り込む。
3. ？？？は主人公たちの共鳴を警戒して「なぜ言葉が通じる」「その力を使うな」と警告する。誰かを二度と失いたくないという後悔をほのめかすが、正体は伏せる。
4. 封印の異常を検知した黒い霧が**自動的に**動き始める。？？？が手動で霧を送ったわけではない。霧に襲われる最終守護者を主人公たちが助け、番人の意思が変わる。
5. 霧を退けるが、その残りが森の外へ向かう。モリィは「また、見つかったのか」と漏らし、その後は普段どおり手助けする。主人公は別の共鳴者を救うため旅立つ。
