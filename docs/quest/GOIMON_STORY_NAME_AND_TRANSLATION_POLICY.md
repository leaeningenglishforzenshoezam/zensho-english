# GOIMON QUEST｜物語の名前表示・通訳演出仕様（2026-10-18）
状態：採用するシナリオ仕様。既存セーブ・本番UIの修正は別工程。

## プレイヤー名
- ログイン済みの場合、**プロフィールで登録したユーザー名**を表示する（Googleアカウント本名の自動使用ではない）。
- 現行 `cloud_sync.js` では `sessionStorage['goimon_cloud_session_v1']` の `displayName` に `details.username` を反映する。ログイン状態を検証した上で利用する。古いセッション・ログアウト・空文字は使わない。
- ログインしていないときは **「あなた」** と表示する。
- セリフラベルと名前への呼びかけは `{{playerName}}` で統一。UIではHTML文字列結合を避け `textContent` で表示する。

## 相棒名
- 現行 `goimon.js` の `getGoimonPrimaryName(g)` と同じ規則にする：`g.nickname` が設定されていればその名前、なければ `GoimonDex.getEntry(type,stage).name` 等を使った図鑑名。
- 物語で連れている**対象のゴイモン**を参照する。所持ゴイモンを勝手に先頭から選ばない。ステージや進化によって図鑑名は変化する。
- `{{partnerName}}` を台詞ラベル・呼びかけに使う。
- 名前が未設定で図鑑データも取得できない場合は「相棒ゴイモン」を一時表示し、ゲームの保存データは変更しない。

## 通訳・ノベルゲームの表示
**世界設定は維持する**：人間とゴイモンの共鳴はペア単位。ゴイモン同士は相互に会話できる。主人公はモリィや番人の言語を直接理解しない。

ただし読者はストーリー上の会話を読める。ノベル画面は相棒を介して主人公に伝わった会話の**意味を読みやすく編集した字幕表現**とする。
- モリィ、守護者などのセリフは発話者名で**直接**表示する。いちいち相棒の「～だって」「～と言ってる」というセリフを挟まない。
- 初登場時に1回だけ「相棒が、モリィの話すことをすぐに教えてくれた」と地の文で説明する。以後は字幕として自然に話を進める。
- **通訳ができるのは相棒のみ**。相棒が離れたり声を失ったりする展開では、主人公に情報が伝わらない描写を守る。
- 黒い霧が共鳴を妨害する場面では、「相棒との会話が途切れる」ことを演出にする。字幕の省略と魔法的な全員通訳を混同しない。
- 他人の秘密を相棒が訳し忘れたり意図的に伝えなかったりする場合は字幕で情報を先取りしない。物語上の情報の受け渡しを優先。
- モリィの意味深な独白や話題転換を多用しない。章末「また、見つかったのか」は少数の重要な伏線として残す。

## 書き換え前→書き換え後
修正前：
【モリィ】「石碑はこの先だよ」
【相棒】「石碑はこの先だって」
【主人公】「わかった」
修正後：
【地の文】相棒はモリィの言葉を主人公に伝えながら歩いている。
【モリィ】「石碑はこの先だよ。滑りやすいから気をつけて！」
【`{{playerName}}`】「ありがとう。ほら、`{{partnerName}}`、急がないで」
【`{{partnerName}}`】「えー、もう見えてるのに！」

## 実装に進む際の必須確認
1. `cloud_sync.js` と同じアカウントセッション判定を使用し、ログインしていないユーザーに過去の表示名を漏らさない。
2. クエストで選択した相棒のIDを確定し、現在の表示名と図鑑名を既存データから求める。
3. ログイン・ログアウト、ゴイモンの改名・進化・相棒の切替に追従する。保存形式は変更しない。
4. シナリオ本文に直書きされた「主人公」「相棒」を動的ラベルへ置換する。
